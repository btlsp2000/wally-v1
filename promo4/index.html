The system is driven primarily by the Command Line Interface (CLI) at the bottom of the screen using explicit commands: LINE spawns a standard 0-thickness geometric path, WALL creates a thickened polyline structure, CIRCLE yields a native circle where width equals radius and depth equals tube wall, DIM generates a dimension tool, TEXT places an annotation, and STAIR constructs a parametric stair tread array.
SECTION 4: UTILITIES
SYSTEM OPERATION
Automation & Macro Execution
Entering numerical values like X,Y appends a coordinate point to the active path, ERASE or the DEL key deletes the selected entity, ZOOM E executes a Zoom Extents to fit your entire drawing on screen, DXF compiles all visible layers into a 2D AutoCAD file for CNC/Laser fabrication, HAL toggles a high-contrast presentation view, and SCRIPT launches the Macro Interpreter to batch-generate complex geometry directly from an external data file.
SECTION 2: NAVIGATION
Canvas Control & Point Insertion
Canvas navigation is straightforward: click and drag the Right Mouse Button, hold the ALT key with a Left-Click, or use the Middle-Click wheel to pan; scroll the mouse wheel to zoom; and Left-Click any entity to select it and open its property data matrix. To append custom spatial matrices directly, click into the Coordinates box to input cartesian numerical coordinates.
