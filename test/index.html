NEW FEATURE: CHAIN ENTITY

The CHAIN command allows you to link multiple distinct coordinate sets into a single continuous polyline. Separate each block of coordinates with a blank line in the property panel. Wally will automatically draw a "joiner" line between the end of one block and the start of the next.
