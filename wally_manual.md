1. Philosophy: Speed of Thought Drafting
WallyCAD is built on the QuickClick (QC) interface, a gesture-based system designed for draftsmen who need to move as fast as they think. By utilizing an 8-Division Command Radial, users can trigger complex AutoLISP routines with minimal mouse travel.

2. Core Features
Geometry Engine: High-precision Cartesian math optimized for structural steel and architectural layouts.

Dual-Line Construction: Native routines for generating wall systems and structural frames simultaneously.

SquareFont Integration: Includes the custom 5x5 grid matrix typeface for all technical notation and branding.

CofP Adaptation: Specialized geometric generators for calculating pool table physics, including pocket-drop trajectories and bank-angle vectors.

3. The "Sandra" Field Workflow
Designed for the mobile draftsman, the "Sandra" workflow allows for:

Rapid Field Input: Capture dimensions using simplified command aliases.

Cloud Sync Troubleshooting: Built-in verification to ensure local .lsp changes stay synced with the btlsp.tripod directory.

Vector Export: Clean output for 3D printing (e.g., the Star Destroyer prototype) or CNC woodworking.

4. Installation & Setup
Download the .zip from Gumroad.

Extract the .lsp files to your CAD support folder.

Type APPLOAD in your command line and select the wally_main.lsp file.

Type WALLY to initialize the QC Radial.
